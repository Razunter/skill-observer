Write every section, body and reference file with `\n` line ends: Prepare refuses a change holding a carriage return, which the Ask form cannot show.

Prepare reads each target rule and reference file itself and canonicalizes each change into exactly what `observer_resolve` would write or delete; that change and the merged evidence stay saved on the branch, out of the tool result. Per eligible proposal it returns its `reference` (`{ reviewToolCallId, candidateId, contentHash }`), `fingerprint`, kind with skill or project `target`, `gist`, and the `preview` rendered from its change; a stale proposal returns `previews` instead, its Update then its Delete. An on-read append also returns `amendmentSections`: the `## ` headings the skill's on-read amendment holds now, empty when it has none yet. When one of them already covers the section, drop or rework that candidate rather than ask for a duplicate. Prepare canonicalizes identity, merges duplicate evidence and removes scoped declines (without checking a declined proposal's target) before exposing `judgeStates`. Fix a rejected candidate and prepare again; a preview is never edited by hand.
