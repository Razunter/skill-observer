A `direct-edit` of an installed local or managed skill, an `on-read-append` and a `rule` also carry `diagnosis`: `inspection`, the ID of this pass's inspect call of that skill; `explanation`, why the inspected guidance does not already address the finding, with the check that could prove it wrong and its result; `delta`, one sentence on what a future agent will do differently; and `citations`, each a `source` path the inspection lists with `lines` (`{ from, to }`) or a `## ` `section`. Prepare refuses a repair without them. Prepare, and Select again before its form, refuse a repair whose inspection is from an earlier pass or another branch, or whose skill file, rules or reference files changed since: inspect the skill again, cite the new receipt and prepare again; never adjust a citation to fit. The form shows them once beside the preview, so keep them short and cite rather than copy source text.

A new skill carries `diagnosis` too, without `citations`: `inspection`, the ID of this pass's new-skill search; `explanation`, why each match does not fit; and `delta`. Prepare, and Select again, refuse it once a skill of that name exists or a searched source or skill file changed: search again with the same `terms` and prepare again.

Write every section, body and reference file with `\n` line ends: Prepare refuses a change holding a carriage return, which the Ask form cannot show.

Prepare reads each target rule and reference file itself and canonicalizes each change into exactly what `observer_resolve` would write or delete; that change and the merged evidence stay saved on the branch, out of the tool result. Per eligible proposal it returns its `reference` (`{ reviewToolCallId, candidateId, contentHash }`), `fingerprint`, kind with skill or project `target`, `gist`, and the `preview` rendered from its change; a stale proposal returns `previews` instead, its Update then its Delete. An on-read append also returns `amendmentSections`: the `## ` headings the skill's on-read amendment holds now, empty when it has none yet. When one of them already covers the section, drop or rework that candidate rather than ask for a duplicate. When that amendment's text is not in your context, read it at the path the preview names before asking: a heading does not show what a broad section already covers. Prepare canonicalizes identity, merges duplicate evidence and removes scoped declines (without checking a declined proposal's target) before exposing `judgeStates`. Fix a rejected candidate and prepare again; a preview is never edited by hand.
