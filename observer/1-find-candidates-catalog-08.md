**Skill catalog observations** record which skills the system prompt listed, with their descriptions as shown then, when the `before_agent_start` hook ran for a prompt. When session evidence suggests the agent missed a skill that should have applied, look it up with `observer_review` `action: "catalog"` before judging its description: by exact name in `skill`, or, when you don't know which skill should have applied, by words of the task in `terms`, which an observed description must all contain. To get the latest observation at or before the evidenced problem, its real position and the known gaps between, pass `at` with the ID of the entry where the problem happened; that observation was made at its own prompt, not at every request since. The lookup also lists what OMP's later skill notices and compactions changed for that skill, and known capture gaps; judge the state at the point of the evidenced problem. Results come in pages: continue with the returned `cursor`, and search again without it when told the evidence changed. A listing is what the hook saw, not proof the model received it; an unlisted or unknown result, no match or a gap is not proof the skill was unavailable, and no observation is a finding by itself.

**Suspected missed trigger.** Start from an evidenced session problem, never from an installed or unused skill. Look the skill up as above, inspect its current guidance with `action: "inspect"`, then decide which happened: the skill was not selected, it was selected but failed to load, or it was loaded and its guidance ignored, which is an ordinary repair of that guidance. Before blaming a description, weigh the evidence against it: the task lies outside the description, the skill is meant for the user to invoke, its tools were unavailable, the read failed, a loaded skill or an existing rule covered the task, or the environment failed. Catalog evidence supports a suspected missed trigger, never a confirmed one; the current catalog and the installed skills show nothing about what was listed then. A description defect of a local or managed skill is a direct edit whose diagnosis cites the inspection and says the missed trigger is suspected, asked like any other. One of an upstream or plugin skill is a report item with the proposed description and the next action, such as reporting it to the skill's owner, and no prepared amendment, direct edit or ledger record. An on-read amendment reaches the agent only once the skill is read, so it never fixes selection; propose no description override, copy of the skill or preload.
