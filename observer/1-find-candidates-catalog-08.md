**Skill catalog observations** record which skills the system prompt listed, with their descriptions as shown then, when the `before_agent_start` hook ran for a prompt. When session evidence suggests the agent missed a skill that should have applied, look it up with `observer_review` `action: "catalog"` before judging its description: by exact name in `skill`, or, when you don't know which skill should have applied, by words of the task in `terms`, which an observed description must all contain. Pass `at` with the ID of the entry where the evidenced problem happened to get the latest observation at or before it, its real position and the known gaps between; it was observed at that prompt, not at every request since. The lookup also lists what OMP's later skill notices and compactions changed for that skill, and known capture gaps; judge the state at the point of the evidenced problem. Results come in pages: continue with the returned `cursor`, and search again without it when told the evidence changed. A listing is what the hook saw, not proof the model received it; an unlisted or unknown result, no match or a gap is not proof the skill was unavailable, and no observation is a finding by itself.
